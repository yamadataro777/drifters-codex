# The Drifter's Codex

> **物語駆動型 英単語学習Webアプリ**
> 16の島を渡る漂流者になって、失われた言葉(英単語)を取り戻していく。

タイプライターで流れる物語の中に英単語が散りばめられていて、読み進めながらその場で意味を答える。覚えた単語が金色に光って物語が続く。

## 特徴

- **物語と単語が完全連動** — 物語の流れの中で英単語に出会う(単独のカード暗記ではない)
- **タイプライター演出** — 物語が一文字ずつ流れる。interactive 語句に達すると一時停止 → 入力モーダルで意味を答える
- **3ゲート学習 + SRS** — 物語(遭遇) → 別画面(再会タイピング・想起例文穴埋め) → mastered → 1/3/7/14/30日の Leitner box 復習
- **16章のミステリー物語** — 全章を貫く縦糸あり。漂流者と「黒船の主」の二重身、月の満ち、七人の番人、最後の言葉
- **報酬演出** — 正解時の chip 金色アニメ、連続正解コンボ(2/4/7段階)、段クリア時の全画面オーバーレイ
- **未来の漂流者へのメッセージ録音** — 音読録音 + 翌日「昨日の声」再生
- **旅日記コピー** — 訳した語で Tweet 作成 → Claude/ChatGPT 添削プロンプトをクリップボードに

## 語彙

| 集合 | 語数 | 出典 |
|---|---|---|
| AWL Sublist 1–10 | 570 | Coxhead (2000) Academic Word List |
| 学術頻出拡張 (Sublist 11–15) | 330 | 一般的な学術文章で頻出する単語 |
| **合計** | **900** | TOEFL ランクA 相当 |

各単語に: 品詞・日本語訳・古文体の碑文(英文+和訳)・現代例文(英文+和訳)。

## 起動方法

ローカルで動かすだけ。サーバ不要(ただし `python -m http.server` 推奨、localStorage を使うため):

```bash
cd drifters-codex
python3 -m http.server 8000
# → http://localhost:8000/ をブラウザで開く
```

## ディレクトリ構成

```
drifters-codex/
├── index.html              # エントリー
├── app.js                  # 学習ロジック・SRS・UI制御
├── styles.css              # 神話×ミステリー トーンのCSS
├── data/
│   ├── manifest.js         # 16章メタデータ + 全900語インデックス
│   ├── chapters/
│   │   ├── chapter_01.js   # 各章 = 5段の物語 + 56〜57語
│   │   └── chapter_NN.js
│   ├── _source/            # 語彙CSV原本
│   │   ├── awl_570.csv
│   │   └── toefl_rank_a.csv
│   └── _drafts/            # 物語草稿・碑文ドラフト
│       ├── story_drafts.v2.md       # 全16章 ミステリー軸
│       ├── story_drafts.v1.md       # 旧 神話寓話版(履歴)
│       └── inscriptions.jsonl       # 各語の碑文・例文
└── scripts/
    └── build_chapters.py   # CSV + 物語MD → JS 変換ビルダー
```

## 物語データの再生成

物語やCSVを編集したら:

```bash
python3 scripts/build_chapters.py
```

これで `data/manifest.js` と `data/chapters/chapter_NN.js` が再生成される。

## 物語のあらすじ(ネタバレ控えめ)

世界からある日「抽象を扱う言葉」が一斉に消えた。記憶を失った漂流者が、海に浮かぶ16の島を順に巡り、失われた言葉を取り戻していく。月が満ちる前にすべての島を巡らなければ、海は閉じる。

各島で出会う住人たちは「あなたは前にもここに来た」と告げる。漂流者は自分が世界を救うために何かをした七人目の番人だったのか、それとも言葉を消した張本人なのか——黒い帆の船に追われながら、彼は自分の正体に近づいていく。

最後の島の灯台で、彼は本当の名を取り戻し、最後の言葉を口にする(あるいは、しない)。

## キー設計

### 3ゲート学習

| ゲート | 形式 | UI |
|---|---|---|
| 遭遇 Encounter | 英単語 → 日本語訳タイピング | 物語パネル内ポップアップ |
| 再会 Reunion | 意味 → 英単語タイピング | 別画面 Stele Encounter |
| 想起 Recall | 例文穴埋め | 別画面 Stele Encounter |

3ゲート連続正答で mastered → Leitner box (1/3/7/14/30日) で「磨き直し」(SRS)。失敗で box が1段戻る。

### 「楽しさ」の4軸

| 軸 | 実装 |
|---|---|
| ゲーミフィケーション | 16島の航海図(SVG)、ストリーク🔥、連続コンボ、段クリア演出 |
| 物語・感情アーク | タイプライター物語、ミステリー縦糸、各段の hook |
| 身体性・五感 | 音読録音、翌日「昨日の声」再生、神話的シンボル |
| 創作・アウトプット駆動 | 旅日記コピー → Claude/ChatGPT 添削 |

## 既知の制約

- ブラウザ依存(localStorage / MediaRecorder)。Safari は MediaRecorder の一部対応が限定的
- 物語日本語版のみ(英訳なし)。タイプライター速度は `TYPE_SPEED` 定数(app.js)で調整可能
- 録音データは localStorage に Base64 で保存(数MBで容量警告が出る)。永続化は IndexedDB 化が今後の課題
